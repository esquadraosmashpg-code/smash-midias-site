Privacidade e dados

Como tratamos seus dados

O T@RTARUGAS RUNNING utiliza dados de perfil, atividades esportivas, localização durante treinos, informações de saúde fornecidas voluntariamente e outros dados necessários ao funcionamento do aplicativo.

Esses dados são tratados conforme a Política de Privacidade do aplicativo e utilizados exclusivamente para fornecer suas funcionalidades.

Exclusão de conta

Como excluir sua conta

O usuário pode solicitar a exclusão da própria conta diretamente pelo aplicativo.

Perfil → Excluir minha conta

A exclusão remove ou anonimiza os dados pessoais conforme as regras do aplicativo, preservando apenas registros necessários para histórico, segurança, obrigações legais ou integridade de dados relacionados à equipe.

Caso tenha dificuldade para excluir sua conta, entre em contato com o suporte da Smash Mídias.
